# 时序之子使用说明

首次启动选择工作区、风格主题并连上 QQ。未连接时可重试，或退出下次继续。
模型与 AstrBot 配置在设置；五套页面风格和七套主题可随时切换。

## 六页

1. 今日：状态、看 B 站、看视频与打开产物。
2. 她：能力、相处习惯、组件与操作。
3. 连线：账号、会话、消息、桥接。
4. 记录：任务记录与 hermes / keeper / 隙间日志。
5. 体检：重新体检、待处理、通知详情。
6. 设置：外观、模型与 AstrBot、帮助、关于。

## 隔离

新版不导入旧数据，也不卸载旧版。请为新版选择独立工作区。
QQ 扫码登录需要你本人操作；已有 QQ 占用时不要强制接管，按页面提示确认。
