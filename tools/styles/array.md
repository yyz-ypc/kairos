# 术阵 / array

V1.0.0 风格规格（先于实现）。

## 导航模型

任务与依赖工作台。顶部横向任务导航：执行、连接、归档、能力、诊断、配置。主体为操作区，右侧为依赖状态和回执；小窗收起依赖为可切换面板。

## 页面集合与能力去向

保留后端路由 0 今日、1 视频/文章、2 任务详情、3 记录/日志、4 体检、5 能力与维护、6 设置/帮助/更新/组件、7 QQ 连线。各风格按上述导航重新组织；视频与任务详情由快捷入口进入。没有移除能力。

## 密度与层级

高密度；紧凑行与等宽编号；状态和下一步并排。

## 组件规则

每项操作展示依赖、执行状态和回执；所有原有操作仍在对应功能面板。 颜色只能读取 tokens.css 的语义令牌，不得按风格写色值。空态提供下一步，加载态使用 role=status，错误态提供重试和日志入口。

## 动效

120ms 状态切换，无持续旋转装饰。 切换风格仅更新 DOM 和 data-style，不导航或重载 WebView。

## 键盘与响应式

Tab 可达所有按钮；控件必须具备名称。1–6 切主导航，Alt+上下键用于时塔逐层导航。1400×900 使用完整骨架，760×600 使用紧凑导航和分页；正文不得被裁切。

## 适用场景

批量维护、装配、排障。

## 美术候选

关键词：precision ritual circuit, concentric brass diagram, olive parchment and gold, top down technical fantasy illustration。配色由主题决定，美术不作为文字承载底色；参考方向为抽象建筑/编辑插画，避免任何私人人设。
